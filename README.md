# OnePath — радар возможностей с дедлайнами

Личный радар: хакатоны, соревнования и олимпиады, летние и зимние школы, стажировки, исследовательские программы, гранты и стипендии, конференции с приёмом работ, а с 27.10.2026 — и то, куда можно просто прийти: лекции, митапы, фестивали. OnePath читает около 67 источников — каналы Telegram, ленты, страницы программ, Devpost, список летних школ awesome-mlss, лектории и площадки — и раз в неделю ищет по вебу то, что источники пропустили. Посты об одном и том же он склеивает, а модель DeepSeek читает каждый анонс: возможность ли это, тип, тема, где проходит, дедлайн или дата, условия, доступно ли из России и насколько подходит под профиль пользователя. Каждое утро в 08:00 список обновляется: в нём то, до срока чего не больше трёх месяцев, а у особо крупного — шести. Работает как веб-приложение по прямой ссылке (его можно поставить на телефон), без Telegram-бота.

OnePath отделён от [DEEper](https://github.com/MrBoomer1981/DEEper) 27.10.2026: там остались исследования и новости об ИИ, сюда переехал алгоритм поиска возможностей вместе с накопленными данными. Как прошло разделение — в `HANDOFF.md`, что дальше — в `plan.md`.

Оформление — по правилам брендбука AVEN (made by aven) в своих цветах OnePath, взятых с картинки «дверь, открытая в грозу»: тёмная тема «грозовое небо / рама двери / книга / свет в проёме», шрифты Unbounded, Onest и JetBrains Mono. Иконка — та самая дверь: свет из проёма ложится дорожкой.

## Приложение

Три раздела внизу экрана:
- **Возможности.** Сверху «Скоро» — свои возможности, до дедлайна которых не больше двух недель, и свои лекции и митапы, до которых не больше недели (вместо напоминаний бота). Ниже — когда обновился список, фильтры по теме (ИИ, техническое, наука, прочее), месту (свой город, СНГ, мир) и типу, «Новые» (что пришло этим утром), «Ждём» (крупные ежегодные события, регистрация на которые обычно уже открыта, а радар их ещё не нашёл), «Открытые» и сколько ещё ждёт своего срока за окном. Касание открывает карточку: что это, почему подходит, дедлайн и даты, формат, кто может участвовать, доступно ли из России, призы, стоимость. В карточке — «Страница подачи», «В мои», «Регистрация есть», «Исследовать» (исследование в DEEper) и «Не моё».
- **Мои.** Выбранные возможности: «Регистрации ещё нет», «Регистрация есть», «Прошли». Кружок слева отмечает регистрацию одним касанием. Если анонс перенёс дедлайн, это видно в строке и в карточке.
- **Настройки.** Профиль, по которому модель оценивает, что подходит (его новый текст — повод перечитать открытые возможности); свой город (события там — в фильтре по месту, а лекции, митапы и фестивали офлайн в других городах не показываются); какие типы показывать; источники — добавить канал, ленту или страницу программы, выключить или вернуть; поиск по вебу; граффити. Внизу — состояние: когда обновился список, сколько источников работает, сколько потрачено на модель в этом месяце.

## Запуск на своём компьютере

Нужны [uv](https://docs.astral.sh/uv/) и ключ [DeepSeek](https://platform.deepseek.com/api_keys); Docker — для локального SearXNG, если нужен недельный поиск по вебу.

```bash
cp .env.example .env          # впишите DEEPSEEK_API_KEY (и SEARXNG_SECRET: openssl rand -hex 32)
docker compose up -d          # локальный SearXNG на 127.0.0.1:8080 для недельного поиска
uv run app.py                 # приложение и радар в одном процессе: http://127.0.0.1:8501
```

В пустой папке `reports/` первый проход опрашивает все источники (около 100 секунд), а модель дочитывает анонсы за три месяца в пределах дневного лимита (4 ₽). Бесплатно, с тестовой моделью: `uv run dev/mock_llm.py` и переменные из `CLAUDE.md`.

## Из чего состоит

| Часть | Что делает |
|---|---|
| `my_browser/core` | веб-приложение (NiceGUI): «Возможности», «Мои», «Настройки», вход |
| `my_browser/news` | радар: источники, склейка постов в сюжеты, чтение моделью, утреннее обновление, календарь ежегодных событий, поиск по вебу; база `reports/news.sqlite`. Имя `news` осталось от DEEper, где эта часть читала и новости |
| `my_browser/common` | общее: пути, вызовы между частями, учёт стоимости |
| `eval/opps` | замер чтения на 69 размеченных настоящих анонсах |
| `proxy` | Cloudflare Worker: адрес, который открывается из России без VPN |

## Деплой на Railway

Railway собирает `Dockerfile` из ветки `main` при каждом пуше и запускает `app.py`. Нужны том на `/app/reports` (база, логины) и переменные `DEEPSEEK_API_KEY`, `APP_PASSWORD`, `TAVILY_API_KEY` (недельный поиск по вебу: на Railway нет SearXNG) и, по желанию, `RESEARCH_URL` — адрес DEEper для кнопки «Исследовать». С телефона в России приложение открывается через свой Cloudflare Worker (`proxy/`): адрес Railway без VPN не открывается. Адреса этого приложения в публичный репозиторий не попадают.

## Деньги

Модель — DeepSeek Flash, до 40 ₽ в месяц (не больше десятой части в день; 30 ₽ до лекций 27.10.2026); каждый вызов считается по реальным токенам и тарифам DeepSeek с ночной скидкой и виден в «Настройках». Поиск по вебу — бесплатные 1 000 запросов Tavily в месяц, общие с DEEper (радар тратит около 75).
