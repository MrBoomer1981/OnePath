# OnePath — передача (27.10.2026)

Этот файл — для пользователя и для следующей сессии Claude Code в этой папке. Начинать с него, потом `CLAUDE.md`.

## Что это

OnePath — исследовательская часть DEEper (github.com/MrBoomer1981/DEEper), отделённая в ночь на 27.10.2026 по просьбе пользователя: «перенести часть с поиском в новый git… это тоже приложение по прямой ссылке, без тг бота». В OnePath: поиск, обзор на 5–7 минут, продолжения (одно касание, ветка, маршрут), проверка фактов, библиотека, «Фокус», PDF/DOCX/MD. Нет: новостей об ИИ, возможностей (хакатоны и т. п.), Telegram-бота.

Ответы пользователя в ту ночь:
- **DEEper не трогать:** поиск остаётся и там, пока OnePath не проверен. Убрать его из DEEper — отдельная задача, только когда пользователь попросит.
- **Ключи и пароль** для OnePath на Railway — взять из переменных DEEper: тот же `DEEPSEEK_API_KEY`, тот же `TAVILY_API_KEY` (лимит 1 000 запросов в месяц теперь общий на оба приложения), тот же `APP_PASSWORD`.
- **Доступ с телефона без VPN** — свой прокси на Cloudflare, как у DEEper: Worker `onepath`.

## Что сделано при разделении

- Код скопирован из DEEper (коммит `d196b69` там) без истории: в старой истории DEEper есть утёкший `.env`. Взяты `my_browser/common`, `core`, `worker`, `search`, `app.py`, `research.py`, `config.json`, `eval/` (только замер исследований), `dev/`, `static/`, `searxng/`, `docker-compose.yml`, `Dockerfile`, `proxy/` (без архивного `ru/`), `DESIGN_HANDOFF.md`, навык `/check-project`. Не взяты `my_browser/news`, `my_browser/bot`, `eval/news`, `eval/opps`.
- Что поменялось в коде:
  - `app.py` запускает только веб-приложение и очередь исследований;
  - `pyproject.toml`: проект `onepath`, группы `core`, `worker`, `search` (без aiogram, feedparser, fastembed), `uv.lock` пересобран;
  - `common/clients.py` и `settings.py` без части news;
  - продолжения «Для меня» знают только интересы из «Фокуса» (профиль из бота DEEper сюда не переходит);
  - вкладка «Радар» показывает только темы «Что исследовать дальше» из отчётов;
  - видимое название — «OnePath» (заголовки вкладок, манифест, название на экране «Домой», уведомление); иконка, маскот и брендбук — пока DEEper.
- Документы: `CLAUDE.md` (корень и части) переписаны под три части; в корневом есть раздел «Пользователь» — правила работы, которые раньше жили в памяти сессий DEEper. `plan.md` — открытые пункты исследований из плана DEEper. `README.md` — по-русски.
- Проверено локально на тестовой модели: импорты, иконки, исследование целиком (22 источника, 4 продолжения, маршрут, проверка фактов исправила цифру), все страницы отвечают 200, «Радар» и главный экран на 360 px.

## Railway и прокси

Итог выкатки — в разделе ниже («Состояние на утро»). Адреса приложения и прокси — в `PRIVATE.md`: он есть только в этой папке на Mac и не попадает в публичный репозиторий.

## Что сделать пользователю утром

1. Открыть OnePath по ссылке из `PRIVATE.md` (на телефоне — адрес прокси), войти паролем DEEper, запустить один обзор.
2. Переложить папку `OnePath/` из папки DEEper туда, где должны лежать проекты, например `~/Projects/Code/OnePath`. Она — отдельный git-репозиторий; в git DEEper она скрыта только локально (`.git/info/exclude` DEEper), так что переезд ничего там не меняет. После переезда: `railway link` в новой папке (выбрать проект OnePath), если нужен Railway CLI отсюда.
3. Открыть Claude Code в новой папке: сессия прочитает `CLAUDE.md`; попросить её начать с `HANDOFF.md`.

## Открытые вопросы (решает пользователь)

- Убрать ли поиск из DEEper, оставив там радар, возможности и бота? Пока поиск в обоих, и исправление в одном может быть нужно в другом.
- Вкладка «Радар» в OnePath: оставить с темами, переименовать (например, «Темы») или убрать?
- Своё лицо OnePath: иконка, маскот, цвета — или общий брендбук AVEN с DEEper.
- Регион Railway: сервис создан в регионе по умолчанию; из России быстрее Европа (у DEEper в Сингапуре — ~0,56 с на обмен через прокси).
- Переименовать пакет `my_browser` в `onepath` (механическая работа, не срочно).
- Общий ключ Tavily: если обоим приложениям не хватит 1 000 запросов в месяц, завести OnePath свой бесплатный ключ.
